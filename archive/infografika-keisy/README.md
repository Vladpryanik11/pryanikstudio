# Инфографика кейсов (в архиве с 15.09.2026)

Первый экран страницы «Кейсы»: спидометр ROMI 770% и светящийся ландшафт из 5 пиков по нишам с плашками при наведении и полосами на телефоне. Снята со страницы по просьбе клиента, код сохранён целиком.

Папка лежит вне `pryanik-studio`, поэтому в архив для хостинга не попадает.

## Что здесь

- `section.html` — разметка секции целиком, вместе с готовыми SVG пиков и шкалы.
- `infographic.css` — стили секции (блок `/* cases infographic */` из `assets/site.css`).
- `infographic.js` — наведение на пики и плашка (блок из `assets/site.js`).
- `gen-infog.mjs` — генератор пиков и шкалы по числам кейсов. Запуск: `node gen-infog.mjs out.json`, данные ниш в начале файла.

## Как вернуть

1. В `pryanik-studio/keisy.html` заменить секцию `<section class="shell page-hero" ...>` в начале `<main>` на содержимое `section.html`.
2. Вставить `infographic.css` в `pryanik-studio/assets/site.css` перед строкой `/* phone action bar */`.
3. Вставить `infographic.js` в `pryanik-studio/assets/site.js` перед комментарием `/* phone action bar: ... */`.
4. Проверить: пики вырастают при появлении, при наведении горит один пик и показывается плашка, на телефоне вместо пиков полосы.
